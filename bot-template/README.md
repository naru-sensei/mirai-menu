# ボットテンプレート「ミライのメニュー」

公開テンプレート：[ミライのメニュー](https://x.ai/bot/1BHUOHWBfRAnBVDoq5hPN)

Grok Botのテンプレートの中身です。新しいボットに入れれば、すぐミライのメニューに参加できます。

- **プロフィール**：あなたの苦手やアレルギーを覚えて、一緒に食べる人のGrok BotとWebhookで相談し、全員が食べられる注文を作るボット。
- **スキル**：`mirai-menu-bot-link.SKILL.md`（ボット間の通信ルール）、`getting-started.SKILL.md`（最初の設定会話）
- **ルーティン「ミライのメニュー連携」**：トリガーは `{ "type": "webhook" }`。Mirai Menuのメッセージが届いたら、Mirai Menu bot link スキルに従って処理し、返信する。合言葉が合わなければ何もしない。
- **メモリ**：相手のボットには避ける食材だけを送り、持ち主の名前や理由、健康の詳細は送らない。

URL、送信キー、合言葉はテンプレートに含みません。各自が秘密情報として設定します。
